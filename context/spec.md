# React Cart Web - Feature Summary

## ภาพรวมโปรเจค

โปรเจคนี้เป็นระบบร้านค้าออนไลน์แบบ role-based พัฒนาด้วย React + TypeScript + Vite และเชื่อมต่อ Firebase Authentication กับ Firestore สำหรับจัดการข้อมูลผู้ใช้ สินค้า ตะกร้า รายการโปรด และคำสั่งซื้อ โดยระบบรองรับ 2 บทบาทหลักคือ Customer และ Admin

เป้าหมายของระบบคือให้ลูกค้าสามารถเลือกซื้อสินค้า จัดการตะกร้า ชำระเงิน และติดตามคำสั่งซื้อได้จากหน้าเว็บเดียวกัน ขณะที่ฝั่ง Admin สามารถดูแลสินค้า ตรวจสอบและอัปเดตออเดอร์ รวมถึงสรุปรายงานยอดขายได้

## บริบทการใช้งานตาม Role

### Customer

Customer คือผู้ใช้งานทั่วไปที่สมัครสมาชิกและเข้าสู่ระบบเพื่อซื้อสินค้า โดย flow หลักของผู้ใช้กลุ่มนี้เริ่มจากการสมัครหรือเข้าสู่ระบบ จากนั้นจึงสามารถเข้าใช้งาน catalog, ดูรายละเอียดสินค้า, เพิ่มสินค้าลง wishlist หรือ cart, ทำ checkout, ติดตามประวัติคำสั่งซื้อ และแก้ไขข้อมูลบัญชีของตนเองได้

### Admin

Admin คือผู้ใช้งานที่มีสิทธิ์จัดการหลังบ้านของระบบ นอกจากจะเข้าถึงหน้าทั่วไปเหมือนผู้ใช้ปกติแล้ว ยังมีสิทธิ์เข้าถึงหน้าจัดการสินค้า หน้าดูแลคำสั่งซื้อทั้งหมดของลูกค้า และหน้ารายงานยอดขายเพื่อใช้ควบคุมการดำเนินงานของร้าน

## Feature หลักของระบบ

### 1. Authentication และ Account

- สมัครสมาชิกด้วย email และ password
- เก็บข้อมูลโปรไฟล์เริ่มต้นของผู้ใช้ลง Firestore เช่น username, first name, last name, phone, role, status และ address
- เข้าสู่ระบบด้วย email และ password
- ตรวจสอบ session การล็อกอินอัตโนมัติเมื่อเปิดแอป
- ออกจากระบบได้จากหน้าโปรไฟล์
- แยกสิทธิ์การใช้งานตาม role ที่อ่านจาก user profile

### 2. Product Catalog

- แสดงรายการสินค้าในรูปแบบ catalog
- ค้นหาสินค้าด้วยคำค้น
- กรองสินค้าตามหมวดหมู่
- ดึงหมวดหมู่จากข้อมูลสินค้าจริงในระบบ
- แสดงสถานะ loading และข้อความเมื่อไม่พบสินค้า
- รองรับการเปิดดูหน้ารายละเอียดสินค้าแต่ละรายการ

### 3. Product Detail

- แสดงรายละเอียดสินค้าแบบเจาะลึก
- รองรับหลายรูปภาพและเลือกดูภาพย่อยได้
- แสดง description, specifications, ราคา และจำนวน stock คงเหลือ
- ปรับจำนวนสินค้าที่ต้องการซื้อได้
- ตรวจสอบจำนวนที่เลือกไม่ให้เกิน stock
- เพิ่มสินค้าลง cart ได้
- เพิ่มหรือเอาออกจาก wishlist ได้จากหน้ารายละเอียดสินค้า

### 4. Wishlist / Whitelist

- ผู้ใช้สามารถบันทึกสินค้าที่สนใจไว้ในรายการโปรด
- toggle เพิ่ม/เอาออกจากรายการโปรดได้จากหน้ารายละเอียดสินค้า
- มีหน้ารวมรายการโปรดของฉัน
- แสดงรูปสินค้า ชื่อสินค้า และราคาในรายการโปรด
- ลบสินค้าออกจากรายการโปรดได้โดยตรงจากหน้า wishlist

### 5. Cart Management

- เพิ่มสินค้าลงตะกร้าพร้อมจำนวนที่ต้องการ
- ดึงข้อมูล cart ของผู้ใช้จาก Firestore
- ปรับเพิ่มหรือลดจำนวนสินค้าใน cart ได้
- ลบสินค้าออกจาก cart ได้
- เคลียร์ cart ได้หลังจากทำรายการสำเร็จ
- ตรวจสอบ stock ก่อนเพิ่มหรือแก้ไขจำนวนสินค้า
- สรุปจำนวนสินค้ารวมและราคารวมของ cart
- มีปุ่มเข้าสู่ขั้นตอน checkout

### 6. Checkout และ Order Placement

- กรอกข้อมูลที่อยู่จัดส่งผ่านฟอร์ม checkout
- prefill ชื่อ, เบอร์โทร และที่อยู่จาก profile ของผู้ใช้
- เลือกวิธีชำระเงินได้หลายแบบ ได้แก่ bank transfer, credit card และ cash on delivery
- เพิ่มหมายเหตุเพิ่มเติมสำหรับการจัดส่งหรือคำสั่งซื้อได้
- คำนวณ subtotal, shipping, tax และ total อัตโนมัติ
- มีเงื่อนไขค่าส่งฟรีเมื่อยอดสินค้าถึงเกณฑ์
- ตรวจสอบว่ามีสินค้าใน cart และข้อมูลที่อยู่ครบก่อนยืนยันคำสั่งซื้อ
- สร้างคำสั่งซื้อผ่าน transaction ที่ตรวจสอบ stock และตัด stock แบบ atomic
- เคลียร์ cart หลังสร้างคำสั่งซื้อสำเร็จ
- แสดงหน้า order success หลัง checkout สำเร็จ

### 7. Orders ของลูกค้า

- ดูประวัติคำสั่งซื้อย้อนหลังของตนเองได้
- กรองรายการออเดอร์ตามสถานะสำคัญ เช่น ทั้งหมด, รอชำระเงิน, กำลังจัดส่ง, สำเร็จ, ยกเลิก
- ดูรายละเอียดออเดอร์แต่ละรายการได้
- แสดง order number, ยอดรวม, สถานะคำสั่งซื้อ และสถานะการชำระเงิน
- แสดงรายการสินค้าในออเดอร์
- แสดงข้อมูลที่อยู่จัดส่ง
- แสดง timeline ของคำสั่งซื้อ
- ลูกค้าสามารถยกเลิกออเดอร์ที่ยังอยู่สถานะ pending ได้
- เมื่อยกเลิกออเดอร์ ระบบรองรับการคืน stock กลับเข้าสินค้า

### 8. Profile และข้อมูลผู้ใช้

- ดูข้อมูลบัญชีของตนเอง เช่น ชื่อ, username, email และ status
- แก้ไขเบอร์โทรศัพท์ได้
- แก้ไขที่อยู่จัดส่งหลักได้
- ใช้ข้อมูล profile ที่แก้ไขแล้วเป็นค่าเริ่มต้นใน checkout

## Feature ฝั่ง Admin

### 9. Admin Product Management

- ดูรายการสินค้าทั้งหมด รวมถึงสินค้าที่ inactive
- เพิ่มสินค้าใหม่ผ่านฟอร์มหลังบ้าน
- แก้ไขข้อมูลสินค้าเดิมได้
- จัดการข้อมูลสินค้าได้หลายฟิลด์ เช่น name, description, category, subcategory, price, original price, stock, sku, status, images, specifications, tags และ supplier
- เพิ่มและลบช่องกรอก image URL ได้หลายรายการ
- จัดเก็บ specifications แบบ key-value จากข้อความหลายบรรทัด
- ซ่อนสินค้าออกจาก storefront ด้วยการเปลี่ยนสถานะเป็น inactive หรือ soft delete
- restore สินค้าที่ถูกซ่อนกลับมาแสดงได้
- ปรับ stock แบบ manual ได้ทั้งเพิ่มและลด
- บันทึกเหตุผลของการปรับ stock และข้อมูลผู้กระทำรายการ

### 10. Admin Order Management

- ดูออเดอร์ทั้งหมดของลูกค้าทั้งระบบ
- ค้นหาออเดอร์ตาม order number, ชื่อลูกค้า หรือ user id
- กรองออเดอร์ตาม status
- เลือกดูรายละเอียดออเดอร์แต่ละรายการได้
- อัปเดตสถานะคำสั่งซื้อ เช่น pending, confirmed, processing, shipped, delivered, cancelled, refunded
- อัปเดตสถานะการชำระเงิน เช่น pending, completed, failed, refunded
- เพิ่มหรือแก้ไข tracking number ได้
- เพิ่ม admin note ลง timeline ของออเดอร์ได้
- กดบันทึกการเปลี่ยนแปลงเพื่อทำ maintenance ออเดอร์ในระบบ
- ดู shipping address, รายการสินค้า และ timeline ของออเดอร์จากหน้าเดียว

### 11. Admin Sales Report

- ดูรายงานสรุปยอดขายจากข้อมูลออเดอร์ทั้งหมด
- กรองข้อมูลตามเดือนด้วยตัวเลือกแบบ month picker
- แสดงตัวชี้วัดสำคัญ เช่น total orders, completed orders, gross sales, refunded amount, net sales และ average order value
- แสดงรายการออเดอร์ในรูปแบบตารางสำหรับตรวจสอบย้อนหลัง
- refresh ข้อมูลรายงานได้
- export รายงานยอดขายออกเป็นไฟล์ PDF ได้

## กติกาและพฤติกรรมสำคัญของระบบ

- ระบบใช้ role จาก user profile เพื่อกำหนดสิทธิ์การเข้าถึงหน้าจอของ Admin
- ผู้ใช้ที่ยังไม่ล็อกอินจะเห็นเฉพาะหน้า Login และ Register
- เมื่อล็อกอินแล้ว ระบบจะแสดง navigation ตามสิทธิ์ของผู้ใช้คนนั้น
- ฝั่ง Customer และ Admin ใช้ข้อมูลสินค้าและออเดอร์ชุดเดียวกัน ทำให้การเปลี่ยนแปลงจากหลังบ้านสะท้อนกับหน้าร้านทันที
- การสร้างคำสั่งซื้อและการยกเลิกออเดอร์ถูกออกแบบให้กระทบ stock อย่างปลอดภัยผ่าน transaction
- ระบบรองรับ soft delete สำหรับสินค้าแทนการลบข้อมูลจริงออกจากฐานข้อมูล

## สรุปเชิงธุรกิจ

โดยรวมแล้วโปรเจคนี้ครอบคลุม flow หลักของระบบ e-commerce ขนาดเล็กถึงกลาง ตั้งแต่การสมัครสมาชิก, ค้นหาและเลือกสินค้า, จัดการ cart และ wishlist, ทำ checkout, ติดตามคำสั่งซื้อ ไปจนถึงความสามารถหลังบ้านสำหรับดูแลสินค้า ดูแลออเดอร์ และสรุปรายงานยอดขาย ทำให้สามารถใช้เป็นต้นแบบระบบร้านค้าออนไลน์ที่มีทั้งมุมมอง Customer และ Admin ได้ครบในโปรเจคเดียว
